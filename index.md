# Politique de confidentialité — Assistant Loca Materiel

**Dernière mise à jour : 20 octobre 2026**

## 1. Présentation

Cet assistant GPT est destiné aux membres du groupe d'étudiants travaillant sur le projet Loca Materiel.

Il permet d'analyser le code source, de consulter les branches GitHub, d'aider à la résolution de problèmes techniques et d'interagir avec les issues et Pull Requests.

## 2. Données traitées

L'assistant peut transmettre à l'API GitHub les informations nécessaires aux actions demandées, notamment :

- Des noms de fichiers, du code source et des informations du dépôt.
- Des descriptions d'issues et de Pull Requests.
- Des commentaires et des modifications de code.

Les conversations avec l'assistant sont traitées par ChatGPT selon les conditions et politiques de confidentialité d'OpenAI.

## 3. Services tiers

L'assistant utilise les services suivants :

- **OpenAI / ChatGPT** pour les interactions conversationnelles.
- **GitHub** pour l'accès aux dépôts et la gestion du développement.

Les données transmises à ces services sont également soumises à leurs politiques de confidentialité respectives.

## 4. Accès au dépôt

L'assistant utilise une connexion GitHub configurée par le responsable du projet. Les opérations effectuées via cette connexion peuvent utiliser les autorisations de ce compte technique.

Les utilisateurs ne doivent pas soumettre de mots de passe, de tokens ou d'autres informations confidentielles dans leurs demandes.

## 5. Conservation et sécurité

Les contenus publiés sur GitHub, notamment les commits, issues et Pull Requests, peuvent être conservés dans l'historique du projet.

Le traitement et la conservation des autres données dépendent des politiques et paramètres des services utilisés.

## 6. Contact

Pour toute question concernant l'utilisation de cet assistant ou les données traitées, contactez le responsable du projet par le canal de communication habituel du groupe étudiant.
